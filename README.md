# PixelVeil

Local, offline PII redaction for screen recordings. Drop in a video, get back
a version with faces blurred and on-screen PII (emails, phone numbers, card
numbers, IPs) automatically blurred or replaced with realistic fake data.
Nothing is ever uploaded — all processing happens on your machine.

See /docs for full roadmap, architecture, decisions, tasks, and testing docs.
