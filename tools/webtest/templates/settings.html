Settings

Tuning knobs for testing — not end-user settings. Changes apply to the next processing run; they reset when the server restarts.

OCR sampling rate

1 = OCR every frame (slowest, most thorough). Higher skips frames between OCR samples. Must be a positive integer.

Face detection confidence

Lower = blur when less certain (catches more faces, more false positives). Default {{ '%.2f'|format(settings.defaults.face_min_confidence) }}.

PII regex patterns

Edit the pattern used to match each PII type. An invalid regex is rejected and the current pattern is kept. No new categories.
